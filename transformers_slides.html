Transformers

Attention-Based Architectures for Vision

Foundations of Computer Vision

Introduction

What Are Transformers?

Recent family of architectures that generalize CNNs (Vaswani et al. 2017; Dosovitskiy et al. 2021)

  • Like CNNs: process signal in independent chunks
  • Unlike CNNs: include attention layers to mix information globally

The Problem with CNNs

CNNs Can’t Compare Distant Regions

CNNs built around locality - different regions processed independently

Problem: No neurons connect to both \(x_1\) and \(x_7\)

Naive Solution: Fully Connected

Every output takes input from every input → \(N^2\) parameters!

Can we do better? Yes: Attention!

Attention

How Attention Works

Focus on relevant parts of input, ignore the rest

Tokens

Tokenizing Images

Split image into patches, represent each patch as a vector \(\mathbf{t} \in \mathbb{R}^d\)

Token Notation

Sequence of \(N\) tokens: \(\mathbf{T} \in \mathbb{R}^{N \times d}\) (tokens as rows)

\[\mathbf{T} = \begin{bmatrix} \mathbf{t}_1^\mathsf{T}\\ \vdots \\ \mathbf{t}_N^\mathsf{T} \end{bmatrix}\]

Two Token Operations

Mixing: Combine information across tokens | Modifying: Transform each token independently

The Attention Layer

Query-Key-Value Mechanism

Three learned projections for attention:

  • Query: What am I looking for?
  • Key: What do I contain?
  • Value: What information do I provide?

Attention Computation

Queries match keys → attention weights → weighted sum of values

Self-Attention

Tokens attend to each other (Q, K, V all from same input)

Self-Attention Expanded

Each query matches against all keys → attention matrix \(\mathbf{A}\)

Why Self-Attention Works

Aggregates information across patches containing the same object

Attention Maps Example

Attention based on color similarity (query = mean patch color)

Vision Transformer Architecture

Transformer vs MLP

Transformers alternate: Attention (mix tokens) → MLP (modify tokens)

Full ViT Architecture

Repeated blocks: Self-Attention → LayerNorm → MLP → LayerNorm (with skip connections)

Permutation Equivariance

Without positional encoding, order doesn’t matter

Transformers vs CNNs

Transformers Are Generalized CNNs

Tokenization ↔︎ Conv patches | QKV projections ↔︎ Learnable filters

Key Differences

CNNs

  • Local connectivity
  • Strong spatial inductive bias
  • Translation equivariant
  • Efficient for small images

Transformers

  • Global connectivity
  • Weak inductive bias
  • Need positional encoding
  • Scale better to large inputs

Summary

  • Transformers enable efficient global information processing via attention
  • Tokens as fundamental data structure (like neurons for MLPs)
  • Self-attention models relationships within sequences
  • Trade-offs with CNNs: global vs local, data requirements, inductive biases
