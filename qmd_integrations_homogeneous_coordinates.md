### fig-rotation_as_convolution

```markdown
::{#fig-rotation_as_convolution}
<iframe
  src="interactive_homogeneous_coordinates/fig-rotation_as_convolution.html"
  width="100%"
  height="700"
  style="border: 1px solid #ddd; border-radius: 4px;">
</iframe>

Geometric transformation as a convolution. The input and output signals are represented as pixel sets with explicit geometry. The convolution kernels are $w_x$ and $w_y$, corresponding to one dimensional convolutions as they only mix input features within the same input vector. The output intensity values are the same as the input.
:::
```
